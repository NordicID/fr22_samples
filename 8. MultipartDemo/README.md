## MultipartDemo

Simple dotnet application that uses multipart handler to write to file on disk through RPC.

Application uses dotnet8, installed from FR22 app center.

### Usage

- Application package must be installed through FR22 webui application interface.

### Generating FR22 application package

#### Visual Studio 2022
- Open solution with Visual Studio 2022
- After successful build, package 'MultipartDemo_1.0.0-app.zip' is generated in the solution folder.

### Publish integration
See project Post-build event.
